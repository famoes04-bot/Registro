# SMC / ICT Analyzer Backend (FastAPI + YOLOv8)

API em Python para análise automatizada de setups de trading baseados no conceito **SMC / ICT**. 
Combina a deteção visual de padrões (MSS, CHoCH, FVG, Liquidity Sweep) com a precisão matemática de níveis HTF (PDH, PDL, EQ).
